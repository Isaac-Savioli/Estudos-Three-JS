Estudos Three.js 🧊
Projeto desenvolvido para explorar a integração e renderização de modelos 3D na web. O repositório foca na construção de interfaces interativas utilizando elementos tridimensionais, manipulação de luzes, texturas e animações fluídas (como a exibição de modelos .glb).

🚀 Tecnologias Utilizadas
React — Construção da interface e componentização.

Vite — Ferramenta de build otimizada para desenvolvimento rápido.

Three.js — Biblioteca principal para a renderização de gráficos 3D no navegador.

💻 Como Executar na Sua Máquina:

Clone o repositório para o seu computador: 
git clone https://github.com/Isaac-Savioli/estudos_three_js.git

Acesse a pasta do projeto:
cd estudos_three_js

Instale todas as dependências necessárias:
npm install

Inicie o servidor local de desenvolvimento:
npm run dev
